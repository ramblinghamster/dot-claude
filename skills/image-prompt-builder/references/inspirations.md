# Inspirations
## Image Prompt Builder — Scene Ideas by Style

Use this file when you need a starting point, want to explore what a style can do, or
just want to get the creative mind moving. Each style has 5 example scenes spanning
different genres — not all are fantasy. Load this file when the user asks for inspiration,
example scenes, or ideas for what to generate.

---

## How to Suggest New Inspirations

If you want to add a new scene idea to any style:

> *"Add this to [Style Name] inspirations: [scene description]"*

Claude will append it to the relevant style's list below and save the file.

When adding, follow the existing format:
- One sentence that sets the scene
- Specific enough to generate — no vague entries like "a fantasy battle"
- Variety is the goal — different genres, moods, and subjects within each style
